期中報告：致理未來超市 LINE 官方帳號分析

掃描瀏覽網頁

🛍️ 多對多 - 好友加入後的歡迎訊息
1. 加入好友的歡迎訊息中，最多可以使用幾則訊息？
根據 LINE 官方帳號規格，一則歡迎訊息（Welcome Message）最多可以包含 5 個訊息泡泡（Message Bubbles）。
2. 未來超市的設計是幾則？
根據分析，未來超市目前使用了 2 則 訊息泡泡：
  • 第一則：文字訊息
  • 第二則：多頁訊息 (Carousel Message)
3. 這幾則中，分別使用那些形式？
  • 文字訊息 (Text)： 用於親切的開場問候（例如：「您可以叫我小未來」）及行動呼籲。
  • 多頁訊息 (Carousel)： 用於視覺化展示超市的商品分類（如飲品、熱食），讓用戶可以左右滑動瀏覽。
4. 你覺得為何要這樣設計？
  • 建立親切感： 透過擬人化稱呼拉近距離。
  • 視覺化導覽： 新好友通常不清楚超市賣什麼，使用多頁訊息能像「櫥窗」般快速展示多樣商品。
  • 提高互動率： 文字中明確引導「點擊活動按鈕」，給予新用戶明確的第一步指令。
💬 多頁訊息 (Carousel Message)
1. 在歡迎訊息中，會使用多頁訊息的設計原因是？
  • 資訊承載量大： 能在不佔用垂直版面的情況下，橫向展示多張卡片（如飲品、熱食、生鮮）。
  • 結構清晰： 每張卡片都有獨立的圖片、標題和按鈕，方便用戶快速掃描。
2. 在歡迎訊息中，超市多頁訊息選擇頁面類型是哪一個？
選擇的是 「商品服務 (Product)」 類型。因為卡片以圖片為主體，並帶有標籤（如「飲料」），適合展示具體商品項目。
3. 每個頁面的動作類型選擇「文字」的原因是？
為了觸發自動回應。選擇「文字」動作，當用戶點擊時，系統會代發關鍵字（如「#查看飲品」），直接在聊天室內觸發自動回覆的菜單或圖片，而不需要跳轉出 APP，體驗更流暢。
4. 請舉未來超市任一個文字動作類型觸發的反應實例。
實例：
用戶點擊「飲品」按鈕 -> 發送文字「未來超市-飲品介紹」 -> 系統自動回傳一張「本月飲品價目表」圖片或優惠券。
🖼️ 圖文選單 (Rich Menu)
1. 超市採用的圖文選單是幾格版型？
採用 大型版型（Large），推測為標準的 6 格版型，以容納集點卡、菜單、活動、預約等多項功能。
2. 圖文選單觸發時機是針對新客(新加入)？是舊客？
針對 所有顧客（新客與舊客）。它是常駐在聊天室底部的導航列，新客用來認識服務，舊客用來查找功能。
3. 超市哪一個選單會觸動自動回應訊息功能？
最可能是 「菜單」 或 「活動」。點擊後發送關鍵字，觸發系統回傳最新的 DM 或活動詳情。
4. 你覺得圖文選單設計有沒有可以改善的地方？
建議改善：實施「分眾圖文選單」。
目前所有用戶看到的選單都一樣。建議針對「未註冊者」顯示「首購優惠/綁定會員」；針對「已註冊會員」顯示「會員條碼/點數查詢」，讓版面更有效率。
⚙️ 自動回應訊息 (Auto-Reply)
1. 自動回應訊息最多可以幾則訊息串？
一組自動回應最多可包含 5 則 訊息泡泡。
2. 自動回應訊息算在計費則數中嗎？
不算。自動回應（包含關鍵字回覆）屬於被動回覆，是免費的功能，不佔用月費方案的額度。
3. 請舉出 3 個目前超市有設定自動回應訊息的關鍵字。
  1. 營業時間：回覆各分店開門與打烊時間。
  2. 停車：回覆賣場停車場位置與折抵標準。
  3. 外送：回覆外送服務範圍或平台連結。
4. 有沒有能設計出回文串引發更多互動的設計？
可以設計 「心理測驗式互動」。例如用戶輸入「想吃什麼」，機器人回問「今天心情如何？」，用戶點選「開心」後，機器人精準推薦「洋芋片與可樂」並附上優惠券。
📢 群發訊息與分眾
1. 群發訊息最多可以幾則訊息串？
一次群發最多包含 3 則 訊息泡泡。
2. 假如你的群發訊息串是 2 個，請問這樣的計費算幾則？
算 1 則 計費訊息（針對每位收訊者）。只要在一次發送動作內（最多3個泡泡），對一位好友發送都只算扣除 1 則額度。
3. 還可以怎麼設定更多受眾類型？
  • 點擊再行銷 (Click Retargeting)：針對點擊過特定商品（如牛肉）圖片的人貼標籤，下次只對這群人推播相關優惠。
  • 加入管道受眾：區分是從實體店面 QR Code 加入的（在地客），還是網路廣告加入的（潛在客）。
🎉 活動策略設計 - 惜食週案例
1. 以惜食週為例，如何設計群發訊息以達成：曝光、分類貼標、轉換報名？
設計策略：使用「圖文訊息 (Rich Message)」搭配「點擊再行銷」。
  • 視覺 (曝光)：設計一張吸睛的海報圖片，強調惜食週的優惠與環保價值。
  • 互動 (貼標)：圖片設為兩個區塊：
    • 點擊「我要搶購」者 → 自動貼上「潛在購買者」標籤。
    • 點擊「活動理念」者 → 自動貼上「理念支持者」標籤。
  • 轉換 (報名)：訊息下方設定明顯的「立即報名」按鈕，連結至表單。

設計原因： 單一訊息即可完成「吸引目光」與「分眾」，且用戶在無形中被分類，利於後續精準行銷。

2. 除了群發，針對新好友或不在清單的人，該設計哪個管道曝光？
建議管道：
  • 圖文選單 (Rich Menu)：將其中一格改為顯眼的「惜食週活動」按鈕。這是最有效的常駐入口，無論新舊好友打開聊天室都一定看得到。
  • LINE VOOM (貼文串)：發布公開貼文並舉辦分享活動。貼文可被分享擴散，能觸及到非好友圈的潛在客群。
  • 歡迎訊息 (Welcome Message)：活動期間暫時更新歡迎詞，確保每一位新加入的好友第一時間得知活動。
