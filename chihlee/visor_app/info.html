核心設計原則

  • CPU-only 邊緣部署 -- 全部推論在 ARM Cortex-A76 上執行，無 GPU/CUDA 依賴
  • 輕量化模型選型 -- YOLOv26n (2.6M) + LSTR (765K) 總大小 <9MB
  • 機車專用 TTC 閾值 -- 較 ISO 15623 汽車標準更嚴格 (1.0/1.5/2.5s)，搭配距離上限防止誤報
  • 三重時序穩定 -- EMA 平滑 (α=0.4) + 突變過濾 (α=0.08) + 15 幀慣性 Coasting

LSTR 車道偵測 + 時序穩定

LSTR (Lane Shape Prediction with Transformers) 以 ResNet18s 骨幹 (765K params) 搭配 Transformer Decoder，輸出有理函數曲線。採用 CULane 權重（城市/彎道路況），適合台灣道路交通環境。

  • 有理函數: x = c0/(y-c1)^2 + c2/(y-c1) + c3 + c4*y - c5
  • EMA 平滑: α=0.4 / 突變降為 0.08 + Coasting 15 幀
  • Logspace Y-sampling: 50 pts（近密遠疏）
  • Skip-2 跳幀: 每 3 幀推論一次，攤銷 ~17ms/幀

距離估算 + TTC 威脅分級

基於 per-class 真實寬度 的單眼距離估算（pinhole model），搭配 -3m 偏移（相機至車尾中心校正）。EMA 追蹤相對速度，TTC 閾值針對機車煞車距離收緊。

  • critical: TTC < 1.0s & dist < 2.0m -- 僅 IN_LANE
  • warning: TTC < 1.5s & dist < 4.0m -- 僅 IN_LANE
  • caution: TTC < 2.5s & dist < 8.0m -- 全部車道
  • 邊緣過濾: x < 10% or > 90% 寬度 → safe
  • 新物件降級: age < 3 幀 → 最高 caution

# spatial_fusion.py -- distance & threat core
CLASS_WIDTHS = {"car":1.8, "scooter":0.7, "truck":2.5, "pedestrian":0.5, "bicycle":0.6}
TTC_CRITICAL, TTC_WARNING, TTC_CAUTION = 1.0, 1.5, 2.5

dist = (CLASS_WIDTHS[cls] * focal) / bbox_w - 3  # per-class -3m offset
ttc  = dist / max(rel_speed, 0.1)
rel_speed = EMA_speed(prev_dist, cur_dist, dt, alpha=0.4)

# Lane-position gating
if lane_pos == "IN_LANE":
    level = "critical" if ttc < 1.0 and dist < 2.0 else \
            "warning"  if ttc < 1.5 and dist < 4.0 else \
            "caution"  if ttc < 2.5 and dist < 8.0 else "safe"
elif lane_pos in ("LEFT_LANE","RIGHT_LANE"):
    level = "caution" if ttc < 1.5 and dist < 5.0 else "safe"
elif dist < 3.0:
    level = "caution" if ttc < 1.5 else "safe"

# Edge filter: near frame boundaries -> safe
if bbox_cx < 0.1 * W or bbox_cx > 0.9 * W:
    level = "safe"

# New-object downgrade
if track_age < 3:
    level = min(level, "caution")

效能優化黑科技

Skip-2 跳幀
+108%

車道偵測每 3 幀執行一次，攤銷推論成本 50ms → 17ms。EMA/Coasting 讓跳幀在視覺上不可感知。

TorchScript Compile
+7%

載入時 jit.trace + jit.freeze (~2s)，消除 Python interpreter overhead，穩定幀間變異。

imgsz=256 降解析
+25% YOLO

YOLO 像素從 102,400 降至 65,536 (-36%)，推論 ~32ms → ~24ms。Pi 5 建議啟用。

Logspace Y-Sampling
更穩定

logspace 取樣 50 點（近密遠疏），匹配人類視覺透視，車道線繪製更精確。

未來展望與深度優化

ONNX INT8 量化

將 LSTR CULane 轉換為 ONNX + INT8 格式，預計提升 Pi 5 推論速度 2-5x (→ 20-25 FPS)，實現真正即時邊緣部署。

IMU 傾角校正

導入 IMU (BNO055) 即時車身傾角數據，校正單眼距離估算誤差，並對彎道中的車道線進行視覺補償。

二進位協議

通訊 Payload 從 JSON 遷移至 Protobuf / CBOR 格式，搭配 WebRTC 實現 App 端低延遲影像串流。

軌跡預測

導入車輛軌跡預測模型 (Trajectory Prediction)，提前判定鄰車變換車道或切入行為，實現主動式防禦。
